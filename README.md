HLA-Verify provides deterministic verification of HLA allele nomenclature against the IPD-IMGT/HLA reference releases. It offers an API to check, normalize, and lookup allele names, along with a benchmark (HLA‑Bench) that measures model performance on this task. The service is free for up to 1,000 calls a day with an optional API key for higher limits. Built by bioinformatics engineer Jason Brelsford, it targets laboratories and developers needing reliable HLA name validation without relying on LLMs.

**Areas:** Company · Bioinformatics · Healthcare · API · Verification
